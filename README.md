# Block Arcade — 3 Games in 1

A small, original browser arcade bundle containing:
- **Block Puzzle** — place shapes and clear rows/columns.
- **Brick Breaker** — bounce a ball to clear bricks.
- **Movie Mania** — a family-friendly movie trivia quiz.

## Play offline
1. Download and extract the ZIP.
2. Open `index.html` in a modern browser.
3. No installation, server, account, or internet connection is required for gameplay.

The store button needs an internet connection and opens https://payhip.com/emichal296.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `README.md`, and `LICENSE.txt`.
3. In the repository, open **Settings → Pages**.
4. Select the branch you uploaded to and the root (`/`) folder, then save.
5. GitHub will provide a public URL for the online game.

## Selling on Payhip
Upload the ZIP as a digital product on your Payhip account. Add screenshots, a description, and the online demo link if you publish it on GitHub Pages. Test the ZIP on another browser/device before listing it.

## Notes
- The game is self-contained in `index.html`; it uses no external libraries or remote assets.
- Best scores are saved in the browser's local storage when available, so they are device/browser-specific.
- “Block Arcade” is a working title. Check name availability before commercial branding.
- This project is an original homage to broad arcade genres; it is not affiliated with or endorsed by any existing movie studio or game brand.
